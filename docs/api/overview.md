# REST API Specification

The platform exposes an asynchronous REST API built with **FastAPI** and validated via **Pydantic v2**.

> **Authoritative Schema Notice**: The canonical schema is auto-generated by the running application at `/openapi.json` and interactive Swagger UI at `/docs`. The API surface contains **21 unique URI paths** and **24 HTTP operations**.

## 2. Health & Readiness

### `GET /health`
- **Purpose**: Lightweight process liveness probe for container orchestrators.
- **Status Codes**: `200 OK`.
- **Response**:
  ```json
  { "status": "ok" }
  ```

### `GET /api/v1/health`
- **Purpose**: Deep readiness probe verifying database connectivity, checkpointer availability, and vector store integrity. Features automated self-healing for the PostgreSQL connection pool.
- **Status Codes**: `200 OK` (healthy / degraded non-critical), `503 Service Unavailable` (critical component offline).
- **Response**:
  ```json
  {
    "status": "healthy",
    "version": "0.1.0",
    "database": { "status": "connected", "type": "postgres" },
    "vector_store": { "status": "ready", "type": "chroma" },
    "mcp_server": { "status": "running" },
    "active_llm_provider": "mock"
  }
  ```

## 3. Agent & Orchestration

### `POST /api/v1/agent/run`
- **Purpose**: Single autonomous agent execution loop with direct tool registry access.
- **Request Body**:
  ```json
  {
    "task": "Compute the sum of 45 and 99 multiplied by 3",
    "tools": ["calculator"]
  }
  ```
- **Response (`200 OK`)**:
  ```json
  {
    "task": "Compute the sum of 45 and 99 multiplied by 3",
    "answer": "The result is 432.",
    "tools_used": ["calculator"],
    "iterations": 2,
    "status": "completed"
  }
  ```

### `POST /api/v1/orchestration/run`
- **Purpose**: Full multi-agent LangGraph workflow with Supervisor dynamic routing, specialist execution, memory injection, and state checkpointing.
- **Request Body**:
  ```json
  {
    "task": "Research quarterly revenue trends for company X and calculate growth",
    "thread_id": "thread-12345"
  }
  ```
- **Response (`200 OK`)**:
  ```json
  {
    "task": "Research quarterly revenue trends for company X and calculate growth",
    "thread_id": "thread-12345",
    "answer": "Quarterly revenues expanded by 14.2%...",
    "agents_used": ["research", "data", "final"],
    "status": "completed",
    "execution_time_seconds": 1.45,
    "total_cost_usd": 0.00012,
    "total_tokens": 850
  }
  ```
- **Interrupted Response (`200 OK`)**:
  If an action requires human review, the status returns `interrupted` and pending action fields are populated.

### `POST /api/v1/orchestration/replay`
- **Purpose**: Re-executes an existing thread from a historical checkpoint, allowing optional state overrides, branching (`fork=True`), or mock tool results.
- **Request Body**:
  ```json
  {
    "thread_id": "thread-12345",
    "target_node": "data",
    "override_inputs": { "modified_factor": 1.2 },
    "fork": true
  }
  ```
- **Response (`200 OK`)**:
  Returns the new execution outcome under the new forked `thread_id`.

## 4. Human-in-the-Loop (HITL)

### `GET /api/v1/hitl/pending/{thread_id}`
- **Purpose**: Inspect the pending action, proposed tool arguments, and safety justification of a paused execution thread.
- **Status Codes**: `200 OK`, `404 Not Found` (thread not paused or does not exist).
- **Response**:
  ```json
  {
    "thread_id": "thread-12345",
    "status": "pending_approval",
    "action": "http_get",
    "arguments": { "url": "https://api.github.com/repos" },
    "reason": "External HTTP request requires human confirmation."
  }
  ```

### `POST /api/v1/hitl/resume/{thread_id}`
- **Purpose**: Submit approval decision and optional feedback to resume execution.
- **Request Body**:
  ```json
  {
    "approved": true,
    "user_feedback": "Proceed with fetch."
  }
  ```
- **Response (`200 OK`)**: Returns updated orchestration response after resumed execution.

## 5. Knowledge Base & Hybrid RAG

### `POST /api/v1/knowledge/documents`
- **Request**: `{ "content": "Text body...", "metadata": { "source": "annual_report.txt" } }`
- **Response (`201 Created`)**: Document ID and number of generated chunks.

### `POST /api/v1/knowledge/documents/upload`
- **Request**: Multipart form data with file attachment (`.txt`, `.md`, `.pdf`).
- **Response (`201 Created`)**: Document metadata and ingestion summary.

### `GET /api/v1/knowledge/documents`
- **Response (`200 OK`)**: List of all indexed documents with metadata.

### `DELETE /api/v1/knowledge/documents/{document_id}`
- **Response (`200 OK`)**: Confirmation of document deletion from both metadata store and vector index.

### `POST /api/v1/knowledge/search`
- **Request**: `{ "query": "cloud infrastructure costs", "top_k": 5 }`
- **Response (`200 OK`)**: Ranked array of chunks combining dense cosine similarity and BM25 scoring via Reciprocal Rank Fusion.

### `POST /api/v1/knowledge/query`
- **Request**: `{ "query": "What are the infrastructure cost highlights?" }`
- **Response (`200 OK`)**: Synthesized answer with citations referencing retrieved chunks.

### `GET /api/v1/knowledge/stats`
- **Response (`200 OK`)**: Total documents, total chunks, embedding dimensions, and vector collection name.

## 6. Long-Term Semantic Memory

### `POST /api/v1/memory`
- **Request Body**:
  ```json
  {
    "content": "User prefers JSON formatted responses",
    "scope": "user",
    "memory_type": "preference",
    "importance": 0.8,
    "metadata": { "user_id": "usr_99" }
  }
  ```
- **Response (`201 Created`)**: Created memory record with generated ID and timestamp.

### `GET /api/v1/memory` & `GET /api/v1/memory/{memory_id}`
- Filter by `scope` query parameter or fetch directly by primary key.

### `POST /api/v1/memory/search`
- **Request Body**:
  ```json
  {
    "query": "formatting preferences",
    "scope": "user",
    "top_k": 3
  }
  ```
- **Response (`200 OK`)**: Memories ranked using composite score: $0.65\text{sim} + 0.25\text{importance} + 0.10\text{recency}$.

### `POST /api/v1/memory/consolidate`
- Purges records past TTL and merges semantic duplicates with cosine similarity $> 0.85$.

### `DELETE /api/v1/memory/{memory_id}`
- **Response (`200 OK`)**: Deleted status.

### `GET /api/v1/memory/stats`
- **Response (`200 OK`)**: Memory count per scope and storage breakdown.

## 7. Model Context Protocol (MCP) & LLM Providers

### `GET /api/v1/mcp/health`
- Verifies connection to the local MCP server process.

### `GET /api/v1/mcp/tools`
- Returns all discovered MCP tools (e.g. `mcp.local.calculator`, `mcp.local.text_stats`) with JSON schemas.

### `GET /api/v1/llm/providers`
- Returns the currently active provider (`openrouter`, `gemini`, `groq`, `mock`, `openai`) and configured model name.
